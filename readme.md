# Курсовой проект: Предподготовка и анализ данных

Проект выполнен в рамках дисциплины «Предподготовка и анализ данных». 
Цель работы — очистка «сырого» датасета с продажами автомобилей в Казахстане за 9 месяцев 2019 года и разведочный анализ (EDA) рынка с оценкой позиции автоцентра «Меркур Авто».

## Структура репозитория

- `clean.py` — скрипт предподготовки и очистки данных. 
- `eda.py` — скрипт разведочного анализа данных (EDA) и анализа позиции «Меркур Авто».
- `report.md` / `report.docx` — итоговый текстовый отчёт по проекту.

*Примечание: Исходные данные (autokz2019.csv) и результаты их работы (очищенный датасет, графики, текстовые логи) не хранятся в репозитории, так как они генерируются скриптами автоматически.*
